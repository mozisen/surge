# 导航新增节点管理并调整顺序

## Goal
- 左侧导航新增「节点管理」，放在「服务器管理」下面：集中列出所有服务器上的协议实例（客户端里的一个节点 = 服务器上的一个协议 + 端口），支持筛选。
- 「服务器节点」改名为「服务器管理」。
- 「任务记录」移到「操作审计」前面。

## Requirements
- 导航顺序：总览、服务器管理、节点管理、用户管理、流量统计、监控与通知、备份恢复、任务记录、操作审计。
- 节点管理页（`#instances`）：表格列出所有未删除服务器的协议实例：服务器、协议与内核、端口、服务状态、用户数、用户模式、本周期用量合计、操作（管理实例）。
- 筛选：服务器、协议、服务状态、用户模式，以及关键字搜索（服务器名、协议、端口）；筛选即时生效，显示筛选结果数量。
- 「管理实例」打开现有的实例弹窗（启停、端口、用户、配置信息），行为与服务器详情页一致。
- 页面标题、返回链接等处的「服务器节点」改为「服务器管理」。
- 中文、黑白简约，遵守组件规范；代码放在测试切片之外。

## Acceptance Criteria
- [x] 导航名称和顺序符合要求
- [x] 节点管理页列出所有服务器的实例，各项筛选和搜索可用，空结果有提示
- [x] 「管理实例」打开正确服务器的实例弹窗
- [x] cjs 测试覆盖列表与筛选；`node --check`、现有 cjs、unittest 通过；CI 通过
- [x] 本地预览截图（1280 / 375）确认
