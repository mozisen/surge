# Design: Vaio Panel 黑白运维控制台

## 1. 现状诊断（基于本地模拟截图）

- 典型「SaaS 卡片套件」：统计、节点、侧栏信息全部是同样的 14px 圆角 + 同样的浅阴影卡片，层级只靠卡片边框，没有主次。
- 灰阶跨度太窄（`#262626`…`#737373`…`#e4e4e4`），黑色按钮和正文之间没有中间层，状态徽章几乎全是同一种浅灰块，「失败」「待核对」和「已完成」难以区分。
- 表格行高 16px 上下内边距，一屏只看到 5 条任务；数值列左对齐、非等宽数字，纵向扫读困难。
- 顶部横栏只承载一个面包屑和三个零散动作，占 76px 高度；移动端 7 个导航项挤成 4 列换行网格。
- 指标数字用等宽字体 + 负字距，和正文风格脱节；空状态的虚线图标框偏模板化。

## 2. 设计方向

**「仪表读数」**：把面板当成一台设备的前面板。所有装饰让位于读数——数字是主角，状态用形状表达，结构线条只在承载信息时出现。整页唯一大胆之处是 **机架行 + 分段读数条**：每台服务器像机柜里的一台 1U 设备，内存/磁盘用 10 段刻度条显示，一眼能在列表里看出谁满了、谁离线。其余部分安静、克制。

## 3. Token 系统（只用灰阶）

| Token | 值 | 用途 |
|---|---|---|
| `--ink` | `#000000` | 标题、数值、主按钮、实心状态、焦点框 |
| `--ink-2` | `#333333` | 正文 |
| `--muted` | `#6b6b6b` | 次要文字、表头、单位（白底对比度 5.3:1） |
| `--line` | `#d9d9d9` | 结构分隔线、输入框、轮廓徽章 |
| `--line-soft` | `#ececec` | 表格行分隔、刻度条底色 |
| `--canvas` | `#f5f5f5` | 页面底色、行悬停、只读区块 |
| `--surface` | `#ffffff` | 面板、弹窗、输入框 |

保留旧变量名（`--accent`、`--accent-soft`、`--danger` 等）作为别名指向新值，避免遗漏的规则失效。黑色使用真正的 `#000`，不用偏色近黑。

**圆角分层**（不再全站一种）：徽章/标签 3px，按钮与输入 6px，面板 8px，弹窗 12px。**阴影**：只有弹窗和 toast 有阴影，面板一律无阴影、靠 1px 线分隔。

## 4. 字体

- 字体栈：系统字体，不加载外部字体（R7）。`-apple-system, BlinkMacSystemFont, "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", "Segoe UI", sans-serif`。去掉当前首位的 Inter（大多数机器没装，实际渲染不一致）。
- 数字：全局 `font-variant-numeric: tabular-nums`，读数、表格数值列对齐。等宽字体只用于真正的机器字符串（端口、服务名、命令、配置、备份文件名），不再用于大号指标。
- 字号阶梯（基准 14px，比例约 1.2）：11 / 12 / 13 / 14 / 16 / 20 / 24 / 32。页面标题 24px/600；面板标题 14px/600；读数 32px/500，单位 13px 灰色与数值分开排（`612.0` + `GiB`）。
- 不使用全大写标签、不在标题里单独强调某个词。

## 5. 状态表达（无色彩）

| 状态 | 形态 |
|---|---|
| 在线 / 运行中 | 实心黑点 ● + 黑字 |
| 已完成 | 细勾符号 + 灰字（已结束，不抢视线） |
| 离线 / 已停止 / 已撤销 / 已取消 | 空心圆环 ○ + 灰字 |
| 等待中 / 待连接 / 进行中 | 虚线圆环 + 黑字；运行中的任务（running）用实心点 |
| 失败 / 待核对 | **反白**黑底白字徽章——全页最高强调，因为需要人处理 |

徽章由 CSS 伪元素画标记，`badge()` 输出的类名和文字不变（`.badge.online` 等），因此无需改 JS 结构。

- 侧栏 232px，白底，右侧 1px 线；品牌在顶，导航中，底部放刷新状态、账号设置、退出（S1）。
- 内容区最大宽 1240px，左对齐，左右 40px 留白；页面标题区与正文之间 24px，区块之间 32px。
- 1024–1150px：侧栏收窄到 200px。

### 移动（< 760px）

```
┌─────────────────────────────┐
│ Vaio 管理面板      账号  退出 │  顶栏 56px，吸顶
│ 总览 服务器节点 任务记录 流量… │  单行横向滚动导航，当前项下划线
├─────────────────────────────┤
│ 运行总览                     │
│ [+ 添加服务器]               │
│ ┌──────┬──────┐             │  读数带 2×2
│ └──────┴──────┘             │
│ ● 香港·主节点         3 实例 │  机架行折叠为两行：
│   内存 ▮▮▮▮▮▯ 55%  磁盘 …   │  名称/状态 + 读数
└─────────────────────────────┘
```

### 表格

- 行内边距 10px/16px（原 16px/22px），表头白底、12px 灰字、底部 1px `--line`；行分隔 `--line-soft`；行悬停 `--canvas`。
- 数值列（流量、配额、端口、用户数）右对齐 + 等宽数字：通过列类 `.num` 实现，需要在模板里给对应 `<th>/<td>` 加 class（纯展示属性）。
- 表格内按钮改为 32px 高的紧凑描边按钮；`(pointer: coarse)` 下恢复 44px。

### 节点详情

- 标题行：返回链接（小号灰字，非全大写眼眉）→ 名称 + 状态徽章 → 元信息行（分组 / 主机 / 架构 / 节点程序，以竖线分隔的定义列表，不用 `·`）。
- 提示条（离线、升级、备注、未接管）：统一为左侧 2px 黑线的灰底条，需要操作的放右侧按钮。
- 指标读数带（同 S3），下方 tabs，右侧信息栏改为无边框的定义列表，与主表格用竖线分隔。

### 弹窗

- 统一采用安装弹窗已有的「头部固定 / 中部滚动 / 底部固定」视觉：`.modal-foot` 统一有上分隔线与浅底（仅视觉，不改基础布局规则的语义；安装弹窗的 `dialog.install` 作用域规则保持）。
- 头部 18px/600，关闭按钮 36px 方形；遮罩 `rgba(0,0,0,.4)`，无模糊。
- 表单标签 13px/600，字段间距 16px；帮助文字 12px 灰色。

### 图表（S4）

- 每张图：标题 + 当前值大号读数（同读数带排版）+ 「最高 / 采样点」小字；SVG 内加 3 条水平参考线（0、50%、100% of max）与右侧刻度值、底部起止时间；线条 1.5px 黑，线下浅灰填充（`--line-soft`）表示面积；断线区间保持留白。
- 仍是内联 SVG，`viewBox` 固定，宽度自适应；`role="img"` 与 `aria-label` 保留。

### 空状态

- 去掉虚线图标框。空状态 = 一句说明当前状况 + 一句下一步 + 一个主按钮。首次使用的三步引导保留编号（它确实是顺序流程），改为横向分隔的步骤条。

## 7. 对照简报的复审

| 初版想法 | 问题 | 修订 |
|---|---|---|
| 统计用 4 张大数字卡 + 小图标 | 正是「大数字 + 小标签」默认套路，且与卡片套件同质 | 改为一条读数带，单位分开排，去掉装饰图标 |
| 指标用等宽字体 | 「小号数据用等宽」是生成式默认 | 等宽只留给机器字符串，数字用 tabular-nums |
| 返回链接做成全大写字距眼眉 | 模板化 | 普通 13px 灰色链接 |
| 元信息用「·」串联 | 模板化 | 竖线分隔的定义列表 |
| 侧栏改纯黑 | 「近黑底」也是常见默认，且与黑色主按钮争夺视线 | 保持白底，靠线条和字重 |
| 报纸式零圆角 + 细线 | 另一种默认 | 分层圆角（3/6/8/12） |

## 8. 兼容与契约

- **不变**：所有 `id`、`data-action`/`data-*` 属性、`modal()` 签名、`submitTask` 调用、`update…()` 逻辑、`badge()` 的类名与文字、`protocol-card` 按钮精确标记、`trafficPage()` 依赖集合、`traffic-display.cjs` 断言的文案。
- **会变的模板**：`shell()`（S1）、`summary()/stat()`（S3）、`card()/nodeCards()`（S2）、`emptyNodes()`、`detail()` 的头部与侧栏、`historyDialog()` 的 SVG（S4）、各表格的 `class="num"`、（S5 文案改动用户决定不做）。
- 测试切片边界：`install-form.cjs` 取 `installPortCandidate` 到 `editUser`，`traffic-display.cjs` 取 `let trafficNodeId = ''` 到 `function protocolTable(`。新增帮助函数（如分段条 `meter()`）放在 `card()` 之前，不进入上述切片；`trafficPage()` 内不调用新函数。
- 版本：`platform/vaio/__init__.py` 与 `index.html` 的 `?v=` 升到 `0.3.0-preview.10`，同步 CLAUDE.md 当前开发分支说明。

## 9. 回滚

- 每个提交独立：版本号、外壳、页面、弹窗、图表分开提交，任一可 `git revert`。
- 测试面板：`vaio-panel update` 会生成备份，必要时以上一个 REVISION（`c39fec1`）再执行 `vaio-panel update --ref c39fec1...` 回退。
