# 中转线路：入口端口跟随协议、仅转发端口

## Requirements
1. 入口端口：选择（或切换）落地协议后，各层中转的入口端口自动改为该协议的端口；仍可手动修改。切换中转服务器时不再随机生成，沿用当前协议端口。
2. 落地「协议」增加「仅转发端口（出口机）」选项：
   - 选中后显示「落地端口」输入框，中转只把端口转发到「落地地址:落地端口」。
   - 不关联用户协议、不能导出连接信息；转发协议可选（TCP / UDP / TCP+UDP，nftables 固定 TCP+UDP），默认 TCP+UDP。
   - 此时用户可不选（下拉增加「不指定用户」）；选了用户也只作归属，不做关联。
   - 落地服务器可以是任意已接管服务器（不要求有协议）。
3. 落地协议中，已被其他用户占用的一用户一实例标注「（已被其他用户使用）」并不可选。
4. 列表：仅转发端口的线路落地显示「仅转发 · 端口」，用户列显示「—」，不显示「连接信息」。

## Acceptance Criteria
- [ ] 后端：仅转发线路创建（无用户、无关联、端口与协议校验）、导出被拒；原有线路行为不变；unittest
- [ ] 前端：端口跟随与可改、仅转发选项与字段联动、占用标注；cjs；本地预览
- [ ] 全部测试与 CI 通过
