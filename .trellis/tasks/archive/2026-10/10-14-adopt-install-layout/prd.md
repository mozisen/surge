# 接管即平台管理与安装界面单页化

## Requirements
1. 确认接管服务器时自动切到「以平台为准」：
   - 接管确认弹窗说明将切到平台管理；节点上已有脚本用户时列出将删除的用户数，按钮为「确认接管并切到平台管理」。
   - 后端 `adopt` 在接管后为支持的节点（authority_version=1、accounts_version=1、尚非平台模式）排队 `set_authority platform` 任务；有用户时必须带 `clear_users: true`，否则拒绝。旧节点（不支持）只接管，升级后再切换。
   - 详情页「用户管理」区删除「切回脚本管理」；已接管但仍为脚本模式的节点（旧接管或旧版本）保留「切换为平台管理」作为迁移入口。
2. 安装协议参数页删除「返回选择协议」按钮，在弹窗右上角关闭按钮左侧加向左箭头返回。
3. 安装参数页单页紧凑布局：
   - 不再折叠高级设置；删除「基础设置」「高级设置」「证书设置」等分组标题和多余说明（端口说明、加密方式说明、公钥说明、独立端口说明、凭据生成说明）。
   - 顶部一行：「服务器」与「内核」标签在下拉框左侧同一行，下拉框宽度随选中内容自适应；只有一个内核时不显示内核。
   - 协议提示保留为一行灰色说明。
   - 端口、SNI、加密方式、证书方式、凭据、Reality、Snell 等字段两列网格左右排列；窄屏一列。凭据类字段用占位「留空自动生成」。
   - 证书说明只在 ACME 或已有证书时显示。平台用户勾选紧凑排列。
4. 黑白简约；1280 与 375 宽度可用。

## Acceptance Criteria
- [ ] 接管自动切换（含有用户需确认、旧节点只接管、已有未完成任务时只接管并提示）unittest 覆盖
- [ ] 安装表单字段、提交参数与现有测试一致；cjs 更新；全部测试与 CI 通过
- [ ] 本地预览 1280/375 截图确认
