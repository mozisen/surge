# 平台统一用户管理

## Goal

一个用户可以使用多个协议，时限和流量统一管理。节点脚本可以独立运行，自己就有「统一用户」（一台节点上挂多个协议）；面板新增「平台用户」，把多台节点上的统一用户关联起来，跨节点统一管理，并与节点双向同步。脚本、节点程序（Agent）、面板同步更新。

## 背景

调研结论见 `research/current-state.md`。要点如下：
- 现在的用户只存在于各节点数据库的实例里，身份是 (core, proto, 用户名)，面板没有用户表。
- 计费和到期由节点按单个实例用户执行（Agent 的 panel_quota 和本地 reconcile），没有跨节点汇总。
- Snell 和 SS 一个用户一个端口；其他协议一个实例可以有多个用户。
- 面板每个节点同时只能执行一个任务，并且要求 revision 一致。
- 脚本 `--api` 只读，没有用户写操作。

## Requirements

- R0 脚本独立运行（不依赖 Agent 和面板）时，提供统一用户：挂多个协议用户，到期、配额、重置日、启停统一设置，合计用量，由脚本菜单管理、由脚本定时任务执行。
- R1 面板新增平台用户：用户名、备注、到期日期、流量配额、重置周期、启用状态。
- R2 平台用户关联多台节点，每台节点上对应一个统一用户（在节点新建，或认领已有的）。同步字段双向同步，后改的生效（D11）。
- R3 到期和配额由平台统一判断，按决策 D2、D3 执行停用和恢复。
- R4 用户维度的流量汇总：跨节点、跨协议的当前周期用量、剩余量和各节点、各协议明细。
- R5 已有的实例用户可以迁移或认领为平台用户（D4）。
- R6 凭据策略按 D5。
- R7 节点离线或同步失败时状态可见，恢复后自动收敛，不重放结果未知的任务（D6）。
- R8 脚本、Agent、面板之间有能力协商；旧 Agent 和旧脚本的节点保持现有功能，不被破坏（D7）。
- R9 脚本菜单不锁定已关联平台的用户，本地修改照常生效，并同步回面板；`--api` 提供版本化的统一用户写操作，带事务、幂等、乐观并发、结果查询和崩溃恢复，Agent 通过它写入。
- R10 界面文案用中文，黑白简约，遵守 `.trellis/spec/frontend/component-guidelines.md`。

## 决策记录

- D2 已定：面板判断，节点兜底。面板汇总所有节点的用量，判断到期和超额后给各节点下发停用或恢复。节点保存平台下发的到期日，离线时 Agent 按到期日本地停用。跨节点配额只由面板判断。
- D3 已定：总用量达到配额后停用该用户在所有节点上的统一用户；到重置周期、调高配额或管理员手动重置后自动恢复；手动停用和已到期的不自动恢复。
- D4 已定：手动认领。管理员把节点实例里的现有用户归入新的或已有的平台用户，保留凭据和已用流量；未认领的继续按实例管理。
- D5 已定：每个协议成员的凭据独立；重置凭据可以针对单个成员，也可以一次重置全部。
- D1 已定：面板新增平台用户，每个用户有自己的每月重置日（1–28，0 表示不重置），按面板所在时区的日期切换周期，所有节点共用同一个周期。
- D6 已定：离线节点上的关联显示「待同步」，用量按最后一次快照计算，上线后自动下发最新状态；结果未知的任务仍然等人工核对，不重放。
- D7 已定：只有宣告了平台用户能力的新版节点程序才能关联或认领；旧节点提示需要升级，原有功能不变。
- D8 已定（D10 之后调整）：一个父任务加 4 个子任务，按顺序实现：脚本统一用户（独立运行）→ 脚本 `--api` 统一用户接口 → Agent → 面板。各自提交和验收；父任务负责跨层联调和最终文档。
- D9 已定：开放 `--api` 统一用户写接口，Agent 通过它写入。写接口要补齐事务、幂等、结果查询和崩溃恢复。
- D10 已定：脚本必须能独立运行，包括用户管理。脚本自带节点级统一用户，由脚本自己执行时限和流量；不安装 Agent 也能完整使用。
- D11 已定：接入平台后，脚本菜单和面板双向同步，同一字段两边都改时后改的生效，并在面板提示。跨节点配额永远由面板判断；节点本地按自己的配额兜底。

## Acceptance Criteria（草案）

- [x] 只用脚本（不装 Agent）就能创建统一用户、挂多个协议，到期和合计配额由脚本执行
- [x] 能创建平台用户并关联至少两个节点，各节点的统一用户实际生效
- [x] 在脚本菜单修改已关联用户的到期日期，面板和其他节点随之更新；两边同时修改时后改的生效，并有提示
- [x] 跨节点用量合计达到配额后，所有节点上的该用户都停用；重置周期到达或调整配额后自动恢复
- [x] 到期后所有节点上的该用户停用，延长到期后恢复
- [x] 现有协议用户可以归入统一用户，节点统一用户可以被平台认领，都不重置凭据和用量
- [x] 节点离线时面板显示待同步状态，恢复后自动收敛
- [x] 旧版 Agent 节点不受影响，界面说明需要升级
- [x] 所有检查通过（CLAUDE.md），Node 部分以 GitHub Actions 为准
- [x] 在 docs/ 记录版本、改动、隔离测试结果和真实验收结果，两者分开写

## 验收说明

以上勾选项均为隔离测试结果（函数级、模拟节点、CI 中的真实 CLI 进程），详见 `docs/platform-user-management.md`。真实 VPS 验收未执行，需要另行授权。

## Out of Scope（初定）

- 面向最终用户的自助门户、订阅链接聚合、付费和计费系统
- 不操作生产节点（「香港维多利亚」），真实验收需要另行授权
