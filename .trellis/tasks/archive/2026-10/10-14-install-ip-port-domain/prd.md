# 安装支持 IP 与自定义端口，面板设置更换域名，卸载命令

## 已确认
- 首次安装提示输入域名；直接回车则使用本机公网 IP，以 **HTTP** 访问（不加密，用户已知晓风险）。
- 安装时可输入面板端口（访问面板的端口）：域名模式为 HTTPS 端口（默认 443），IP 模式为 HTTP 端口（默认 8080）。
- 面板设置中可以之后自行填写域名，切换为 HTTPS。
- GitHub README 增加卸载命令（新增 `vaio-panel uninstall` 与 `vaio-agent uninstall`）。

## Requirements
1. 安装脚本：
   - 域名留空 → 自动取本机公网 IPv4（取不到时提示手动输入 IP），HTTP；跳过证书申请。
   - 端口输入（1–65535，回车用默认），检查端口未被占用；域名模式申请证书仍需临时使用 80 端口。
   - 面板地址写入 `VAIO_PUBLIC_URL`（如 `http://1.2.3.4:8080`、`https://panel.example.com:8443`），IP 模式写 `VAIO_ALLOW_HTTP=1`。
   - 结束时打印面板地址；IP 模式提示「未加密，建议在面板设置中绑定域名」。
2. 面板与节点程序允许 HTTP 面板地址（仅面板明确开启 `VAIO_ALLOW_HTTP` 时；节点由面板生成的安装命令带上允许标记）。HTTP 下会话 Cookie 不带 Secure。
3. 面板设置（账号设置旁新增「面板地址」）：显示当前地址；可填写域名（与 HTTPS 端口）申请证书并切换为 HTTPS：
   - 面板无 root 权限，由安装时注册的 root 辅助服务执行（写 Nginx、申请证书、更新面板地址并重启面板），界面显示进度与失败原因。
   - 切换后旧的 HTTP 地址暂时保留，面板通知所有在线节点改用新地址（节点验证能以 HTTPS 访问新地址后才切换）；全部节点切换完成后可在设置中「关闭旧地址」。
4. 卸载：
   - `vaio-panel uninstall`：确认后删除面板服务、程序、配置、数据库、备份、Nginx 站点与系统用户；证书与其他站点保留；可选先导出一份数据库备份。
   - `vaio-agent uninstall`：确认后删除节点程序服务与文件；节点脚本、代理配置与用户保留；指向节点程序内置脚本的定时任务改回 `/usr/local/bin/vless-server.sh`。
   - README 写明两个卸载命令及影响。
