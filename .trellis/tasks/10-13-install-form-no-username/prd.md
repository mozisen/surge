# 安装表单删除用户名并随机端口

## Goal
面板「安装协议」表单不再显示用户名；打开表单时自动生成一个空闲的随机高位端口，不再固定显示 24443。

## 背景
用户名是节点上协议账号的身份标识（统计键、分享链接备注、成员定位），但不需要管理员手填：以平台为准的节点（Agent 0.3.0-preview.13 起）安装空实例，账号名直接用平台用户名；以脚本为准或旧版节点由面板自动生成不重复的名字（`u端口`，重名时加后缀）。

## Requirements
- 删除安装表单的用户名输入框和「生成」按钮，适用于所有节点类型（以平台为准、以脚本为准、旧版节点）。
- 提交时面板在后台自动生成名字并照常发送（兼容旧版 Agent：Snell 和 SS 在旧版 Agent 上需要不重复的名字；新版 Agent 在平台模式下忽略它）。
- 打开表单时用现有的 `installPortCandidate` 随机生成空闲高位端口（20000–65535）；「生成」按钮保留。
- 不改变其他字段和提交参数。

## Acceptance Criteria
- [x] 表单中没有用户名输入；提交参数中的 `name` 为自动生成的不重复名字
- [x] 打开表单即显示随机空闲端口
- [x] `install-form.cjs`、`platform-users.cjs`、unittest、`node --check` 通过；CI 通过
- [x] 本地预览截图确认
