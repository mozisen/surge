# 界面精简与用户默认开启登录（1.3.1）

## 需求
1. 新建用户时填写登录密码（可随机生成，创建后显示一次），即开启登录；删除用户详情中的登录设置。管理员在「编辑用户」中填写新密码即重置（该用户会话失效）。已有用户升级时自动生成随机密码（无人知晓，需在编辑中重置后才能登录）。
2. 备份恢复移入「系统设置」标签，导航删除。
3. 删除侧栏「更新于 时间」。
4. 「一键更新节点程序」移到「添加服务器」左边。
5. 总览「最近任务」改为中转线路列表。
6. 导航「服务器管理」改为「服务器」。
7. 品牌「Vaio 管理面板」改为「VAIO」。
8. 删除各管理页面标题下的描述。

## 约束
- 用户名不能与管理员账号相同（大小写不敏感）；管理员改名不能与任何平台用户同名。
- 接口创建用户不带密码时使用随机密码（兼容），界面强制填写。

## 验收
- unittest 与 cjs 覆盖创建带密码、编辑重置、旧用户随机密码、同名限制、设置标签；本地预览 1280 / 375。
