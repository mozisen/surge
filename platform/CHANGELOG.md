# 更新记录

## 1.2.1

- 修复用户流量一直为 0：用户用量来自节点脚本的流量同步，但脚本只在启用自身 Telegram 功能时才安装同步定时任务，由平台接管的节点从未同步。现在节点程序每分钟自动运行一次流量同步（与节点任务串行，失败不影响到期检查，日志在 `/etc/vless-reality/traffic-sync.log`），平台用户用量约 1 分钟内更新。
- 需要把节点程序更新到 1.2.1（服务器管理 →「一键更新节点程序」）后生效。

## 1.2.0

- 服务器：列表改为显示节点程序当前版本与最新版本（面板版本）；新增「一键更新节点程序」，为可更新的服务器批量创建升级任务，离线、维护中、不支持一键升级或有未完成任务的服务器列出跳过原因。
- 面板更新：每次打开面板在后台检查 mozisen/vaio-panel 的正式版本标签（服务器缓存 6 小时，连不上 GitHub 时静默重试），有新版本在左下角提示；可在面板中直接更新（备份、测试、健康检查与失败恢复与 `vaio-panel update` 相同），有节点任务未完成时不允许更新。
- 系统设置：左下角「面板地址」与「账号设置」合并为「系统设置」，分「账号」「面板地址」两个标签。
- 新装面板与升级都会安装面板更新辅助服务（`vaio-panel-update.path`）；由 1.1.0 升级上来的面板首次打开「面板更新」时自动补装。

## 1.1.0

- 安装：没有域名时直接回车使用本机公网 IP（HTTP）；可自定义面板端口（有域名默认 443，用 IP 默认 8080）。
- 面板地址：在面板中绑定或更换域名，自动申请证书并切换 HTTPS，失败自动恢复；各节点自动改用新地址（节点需 1.1.0 及以上），旧地址在「关闭旧地址」前保留；也可用 `vaio-panel domain`。
- 卸载：新增 `vaio-panel uninstall`（可先 `--backup` 导出数据）与 `vaio-agent uninstall`（保留节点脚本、代理与用户）。
- 已部署的面板升级时自动安装地址辅助服务。

## 1.0.0（正式版）

首个正式版，面板与节点程序版本均为 1.0.0，内置节点脚本 3.7.4-preview.12。

- 服务器：注册与接管（接管即由平台管理用户）、节点设置、回收站、资源历史曲线、一键升级节点程序（失败自动回滚）。
- 节点管理：所有服务器的协议实例集中查看与筛选；单页安装协议，可选择服务器，凭据与证书参数随协议显示。
- 用户：平台用户跨服务器统一管理到期、配额与月度重置，多协议关联，一用户一实例协议的分配，连接信息导出。
- 中转：多层中转线路（Realm / nftables），入口端口跟随落地协议端口，仅转发端口的出口机，经中转的连接导出。
- 端口转发：Realm 与 nftables 规则的新增、修改、启停、删除，与节点脚本和 nft.sh 配置同步，状态与流量。
- 通知：Telegram 管理员通知、流量阈值、每日报告、用户查询机器人与绑定码；不保留发送记录。
- 流量统计、备份恢复、任务记录、操作审计。
- 界面：中文黑白简约，筛选与弹窗下拉使用弹出菜单，控件统一高度，适配手机。
- 安装与升级默认来自 mozisen/vaio-panel，兼容 surge 预览版源码包。
