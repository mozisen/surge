# 更新记录

## 1.6.0

- 面板可以调用节点脚本自己的安装流程安装协议，证书与参数和脚本菜单一致。安装对话框中标注「脚本安装 · 支持自有域名」的协议按节点上报的字段清单生成表单；本版开放 VLESS-Vision（Xray）：端口、自签证书（可填 SNI）或 Let’s Encrypt（填写已解析到本机的域名，需 80 端口可用），以及已装 Trojan 时保留 Trojan 换端口或卸载 Trojan。
- 安装在节点上加锁并备份脚本数据、证书与伪装站点后执行；参数无效、证书申请失败或安装失败时节点恢复安装前状态，执行记录说明被拒绝的参数。选择 Let’s Encrypt 而申请失败时直接失败，不会改用自签证书。
- 平台管理的节点安装后实例无用户，在「用户管理」中分配（与其他协议一致）。
- 节点脚本 3.7.4-preview.16：新增 `--api install` 与安装字段清单；菜单交互不变。
- 需要「一键更新节点程序」到 1.6.0。后续版本逐批开放 VLESS Reality 真实域名、VLESS-WS / Trojan-WS / VMess-WS、TUIC / Naive / XHTTP、ShadowTLS 与 SOCKS。

## 1.5.1

- 修复「重置用量」后用户账号恢复正常、但部分节点上的协议仍是停用：每个节点上的统一用户也按自己的本周期用量对照配额停用，面板此前只清了自己的计数。现在重置用量时同时让关联的每个节点清零；节点上报某用户超额而面板统计未超额时（例如在旧版本重置过），面板自动让该节点清零，已卡住的用户升级后自行恢复。

## 1.5.0

- 多用户 SS / SS2022 可以管理：Sing-box 上的 SS、SS2022 实例不论几个用户，都可以修改端口、启停、重启、卸载；由节点脚本管理用户的节点还可以在实例中新增、编辑、删除用户（此前有第二个用户后实例变为只读）。写入前仍校验运行配置是普通的 SS 入站。
- 所有 SS / SS2022 用户都显示流量：单用户按入站、多用户按用户统计；统计状态按实际采集方式判断；未及时更新的显示「统计未更新」而不是隐藏用量。
- 多用户 SS2022 导出的连接改为「方法:服务端密钥:用户密钥」，可直接使用。SS2022 从一个用户变为多个用户后，原用户需重新导出连接。
- 到期与配额的本地执行覆盖多用户 SS（此前跳过）。
- 节点脚本 3.7.4-preview.15：按用户统计加入 SS2022；面板安装的 SS2022 加入第二个用户时保留服务端密钥（此前新用户无法连接）；新成员 SS2022 密钥长度按加密方法生成（chacha20-poly1305 此前误用 16 字节）。
- 需要「一键更新节点程序」到 1.5.0。

## 1.4.4

- 用户详情「协议 → 新建协议账号」不再列出该用户已有账号的实例，接口也拒绝在同一实例为同一用户再建账号（此前会在同一端口新建同名账号并失败）。

## 1.4.3

- 修复关联用户后显示「同步失败：节点上已存在同一统一用户」：新建成功后，节点程序最多 10 秒内仍上报新建前的旧状态，面板据此又发了一次新建。现在节点程序在任务完成后立即重新读取状态；面板对已同步的关联不再重复新建；已标为同步失败的关联在节点状态确认用户存在且无待同步改动后自动恢复为已同步。
- 节点脚本 3.7.4-preview.14：Snell v5 的最新版本只取 5.x（此前把 Snell v6 的 6.0.0 当作 v5 最新版本，显示「可更新」，更新会因版本校验失败）；启动时作废旧的错误缓存。
- 需要「一键更新节点程序」到 1.4.3。

## 1.4.2

- 修复 Snell v5 显示可更新到 6.0.0：Snell v5 与 v6 是不同内核，最新版本按各自的大版本（5.x / 6.x）取；面板与节点程序都拒绝跨大版本更新（旧节点上报的错误版本按「最新版本获取中」处理）。节点程序更新到 1.4.2 后显示正确的最新版本。
- 总览只保留统计卡片：服务器、当前在线、协议实例、用户、中转线路、今日流量、本月流量（所有服务器网卡收发之和，按面板时区；升级时用最近 7 天的采样补算）。卡片圆角并留间距。
- 「一键更新内核」改为列出所有服务器的各内核当前与最新版本，可逐台更新，也可按内核全部更新；更新中的内核显示「更新中」。
- 删除所有页面底部的「面板版本 · 状态刷新」说明。

## 1.4.1

- 节点脚本 3.7.4-preview.13：Sing-box 的安装与更新（包括 `vless` 菜单的核心管理、指定版本和统计修复）只使用已编译的统计版预编译包（`singbox-stats-binaries`），不再安装官方版本；官方版本只作参考显示。只有本机架构没有预编译包时才安装官方版本并提示无用户统计。
- 需要「一键更新节点程序」到 1.4.1，节点上的脚本随之更新。

## 1.4.0

- 在面板更新内核：服务器详情的「内核」区显示 Xray、Sing-box、Snell v5/v6 的当前版本与最新稳定版本，可单独更新；服务器页「一键更新内核」为所有可更新的服务器逐台排队，并列出跳过原因。
- 更新流程（节点程序在本机执行）：先同步一次用户流量，再备份内核、停止使用该内核的服务、安装新版本、校验版本并启动原来在运行的服务；任一步失败自动恢复旧内核。面板暂停的服务不会被启动。
- Sing-box 一律更新为带用户统计的预编译版本（mozisen/surge 分支 `singbox-stats-binaries`，按本机架构与 libc 选择），「最新版本」以预编译包为准；官方已发布更新而统计版尚未发布时会提示。当前核心不带统计时可更新为统计版。
- 节点程序在后台每 10 分钟读取当前内核版本、每 6 小时查询最新版本，不影响心跳。需要把节点程序更新到 1.4.0 后使用；节点脚本无需改动。

## 1.3.3

安全与稳定性修复（来自代码审计）：

- 登录限流按真实访客地址计算：面板在 Nginx 之后时，只信任来自本机反向代理的一层 `X-Forwarded-For`，一个访客的失败登录不再锁住所有人；直接暴露的后端仍忽略该请求头。
- 以 root 运行的地址与更新辅助程序写状态文件时不再跟随符号链接（先在同目录写临时文件再原子替换）。
- 中转线路导出连接时使用落地节点上该账号的实际成员名，账号被认领或改名后不会导出错误或其他用户的连接。
- 协议用户任务的到期日只接受 `YYYY-MM-DD` 格式。
- 检查 GitHub 新版本时不再占用数据库写锁，网络缓慢时面板不会卡顿。

## 1.3.2

- 中转线路状态考虑用户：用户已到期、流量用尽或已停用，或落地协议已停用时，线路显示原因（红色）并隐藏「连接信息」，用户也无法导出；此前只看各中转服务器的转发规则，用户到期后仍显示「正常」。
- 用户状态「已到期」「流量已用尽」改为红色圆圈。
- 修复用户到期后部分节点仍可使用：到期原由各节点按自己的日期判断（时区不同的节点可能晚一天），且多用户的 SS 端口只在节点脚本每天一次的到期检查中停用。现在面板按自己的时间判定到期后立即向所有节点下发停用（与流量用尽相同），续期后自动恢复；不需要更新节点程序。

## 1.3.0

- 用户登录：管理员在用户详情中为平台用户设置密码即开启登录（可重置、关闭）；用户与管理员使用同一个登录页，用户名即平台用户名，登录后可以自己修改密码。
- 「我的账号」页面：用户只能看到自己的状态、本周期用量与配额、到期与重置日，关联的协议（可查看并复制连接信息和二维码）和中转线路（经中转的连接），看不到任何管理内容、备注、服务器 IP 或协议配置详情。
- Telegram：用户页显示管理员启用的机器人（@用户名），用户可以自己生成绑定码、查看绑定状态和解除绑定。

- 安全：用户会话与管理员会话分开保存，所有管理接口拒绝用户会话；重置密码、关闭登录、删除用户或用户改密码后其所有会话失效；登录失败按 IP 限流；每个用户同时只能有一个连接导出，导出结果只含连接信息。

## 1.2.1

- 修复用户流量一直为 0：用户用量来自节点脚本的流量同步，但脚本只在启用自身 Telegram 功能时才安装同步定时任务，由平台接管的节点从未同步。现在节点程序每分钟自动运行一次流量同步（与节点任务串行，失败不影响到期检查，日志在 `/etc/vless-reality/traffic-sync.log`），平台用户用量约 1 分钟内更新。
- 需要把节点程序更新到 1.2.1（服务器管理 →「一键更新节点程序」）后生效。

## 1.2.0

## 1.1.0

- 安装：没有域名时直接回车使用本机公网 IP（HTTP）；可自定义面板端口（有域名默认 443，用 IP 默认 8080）。
- 面板地址：在面板中绑定或更换域名，自动申请证书并切换 HTTPS，失败自动恢复；各节点自动改用新地址（节点需 1.1.0 及以上），旧地址在「关闭旧地址」前保留；也可用 `vaio-panel domain`。
- 卸载：新增 `vaio-panel uninstall`（可先 `--backup` 导出数据）与 `vaio-agent uninstall`（保留节点脚本、代理与用户）。
- 已部署的面板升级时自动安装地址辅助服务。

## 1.0.0（正式版）

首个正式版，面板与节点程序版本均为 1.0.0，内置节点脚本 3.7.4-preview.12。

- 服务器：注册与接管（接管即由平台管理用户）、节点设置、回收站、资源历史曲线、一键升级节点程序（失败自动回滚）。
- 节点管理：所有服务器的协议实例集中查看与筛选；单页安装协议，可选择服务器，凭据与证书参数随协议显示。
- 用户：平台用户跨服务器统一管理到期、配额与月度重置，多协议关联，一用户一实例协议的分配，连接信息导出。
- 中转：多层中转线路（Realm / nftables），入口端口跟随落地协议端口，仅转发端口的出口机，经中转的连接导出。
- 端口转发：Realm 与 nftables 规则的新增、修改、启停、删除，与节点脚本和 nft.sh 配置同步，状态与流量。
- 通知：Telegram 管理员通知、流量阈值、每日报告、用户查询机器人与绑定码；不保留发送记录。
- 流量统计、备份恢复、任务记录、操作审计。
- 界面：中文黑白简约，筛选与弹窗下拉使用弹出菜单，控件统一高度，适配手机。
- 安装与升级默认来自 mozisen/vaio-panel，兼容 surge 预览版源码包。
