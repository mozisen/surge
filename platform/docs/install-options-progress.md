## 继续补齐：Reality 参数

- VLESS Reality 支持自定义私钥、Short ID，留空自动生成；公钥从私钥推导，避免手工填错密钥对。
- 节点用 OpenSSL X25519 推导，私钥通过标准输入传递，不进入进程参数或执行日志。任务列表脱敏，投递和节点配置保留必要私钥。
- 新参数使用 install_options_version=2 门控；旧版本 1 仍可使用已有高级参数，但不能提交 Reality 新字段。
- 不适用字段保留为禁用状态，用户名生成按钮也跟随字段禁用。Snell 的 SNI 标签明确标注“不适用”。
- 验证：74 项 Python 测试中 73 项通过、1 项跳过（本机 LibreSSL 不具备 X25519；真实推导未验证，模拟 DER 输入输出及失败路径已验证）。前端语法、表单测试通过。未进行线上证书签发、全新节点安装、浏览器视觉或客户端连通性验证。
- 这仍是进行中的分批实现，不代表脚本全部协议已一比一接入，也没有部署服务器。
