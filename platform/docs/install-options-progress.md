# 安装参数升级与 2.2 阶段（2026-09-23）

## 当前任务尚未全部完成

用户要求按脚本全部协议安装流程一比一接入，并在不适用时禁用参数。
本次是该任务的第一批实现，不代表全协议验收或可发布正式版。

已实现（平台 / Agent 0.3.0-preview.3，本地开发）：

- 现有 9 个组合的用户名、自定义凭据（留空自动生成）。
- TLS 证书：带 SAN 的自签、固定路径已有证书、Let’s Encrypt HTTP-01。
- 自有域名和联系邮箱校验；域名、证书有效期和私钥匹配验证。HTTP 签发依赖域名正确指向节点且 TCP 80 可达。占用时拒绝，不停用已有网站。
- ACME 固定续期 hook 仅重载实际引用该证书的共享核心；同域名已受管证书优先复用。失败不自动降级自签。
- Snell v6 模式、DNS IP 列表、IP 偏好、客户端 TFO 写入数据库、运行配置 / 分享链接。
- 首次安装协议补齐已校验 vendor 主脚本、vless 快捷命令及 server 角色；已有脚本不自动覆盖，快捷命令冲突拒绝。
- install_options_version 能力门控：旧 Agent 不接受高级参数。用户选择其它协议时清楚禁用不适用项，提交不包含禁用项。
- 自定义凭据不在任务列表 API 中返回；任务投递及节点数据库仍需保存凭据，服务器数据库与备份必须按敏感数据保护。

未完成的当前任务范围：

- WS / XHTTP / CDN、Vision、SS、SOCKS、TUIC、ShadowTLS、Naïve 全参数写入及共享渲染适配。
- VLESS encryption 模式、端口跳跃和 NAT 事务、伪装网站 / Nginx / Caddy 关联资源恢复。
- ACME DNS 提供商及手工 TXT 分步验证；这些流程不能用自动填写脚本菜单来替代。
- 自定义 Reality 密钥对 / Short ID 与全部协议特有参数。
- 真实浏览器、全新服务器主脚本补装、真实证书签发续期、客户端握手验证。

证书和工具是安装先决资源；失败回滚不自动卸载 ACME 工具、删除新签证书或主脚本，不会假称外部签发已撤销。当前配置事务机制保持不变。

## 2.2 阶段：用户已确认，须当前任务完成后开始

1. 有效期编辑：留空永久、显示节点日期语义、已过期状态及恢复有效期后的执行验证。
2. 用户启停：明确区别于共享服务启停，保留凭据、流量、配额及 Telegram 绑定。
3. 连接信息展示：按协议显示客户端格式与目标端口、可复制、敏感结果到期提醒，禁用 / 过期用户状态提示。
4. Snell 一用户一端口：新增用户引导新增实例，删除用户精确卸载该端口实例；不得影响其它端口。
