# 2.2 / 2.3 预览版

版本：面板与 Agent `0.3.0-preview.4`；脚本 `3.7.3-preview.3`。基于合并后的 `mozisen/surge` 仓库，预览分支 `codex/phase-2-2-3`。

## 用户与计费

- 保留用户名、到期日期、启停、凭据重置、连接导出等现有功能；支持 GiB 配额和每月 1–28 日重置，0 表示不限/不自动重置。
- 配额需要 Agent 声明 `billing_version=1`，并在节点再次验证对应统计源最近 15 分钟有成功采样；无可靠统计时不允许新增非零策略，界面明确显示统计不可用。
- 重用原脚本定时统计累积值，不重复清空内核计数器。原脚本需更新到本提交版本，统计任务与接口需正常工作。未自动为既有节点安装或启用统计任务。
- `panel_quota / panel_reset_day` 为策略；`panel_used / panel_last_used / panel_cycle` 持久保存计费进度。首次配置保留已有累计用量，修改重置日不立即清零。原脚本的全局月重置跳过这些用户；旧用户继续使用原有策略。
- 节点每分钟核对配额和到期日期，不依赖面板在线。超额通过配置移除凭据或停用对应 Snell 服务；不覆盖管理员手动启停意图。原脚本共享渲染器同样识别面板配额。
- 按节点本地日期重置；跨周期尚未采集的增量计入新周期。断电前尚未由原脚本采集的内核流量不承诺恢复；持久化累计值和已采样计费不因 Agent 重启重复累计。
- Snell 仍是一用户一端口。未适配协议只读，不将缺少统计误报成真实零用量。
- 自动执行保存数据库、受影响配置和服务状态备份，失败时尝试恢复。位置为 Agent 状态目录的 `enforcement-backup/`；用户主动写入仍使用独立任务备份、配置版本和任务日志。

## 监控与通知

- 每分钟保存节点系统负载、内存、磁盘、网卡累计值等采样，保留 7 天；节点页展示过去 24 小时曲线，断线区间留空。
- 后台每 30 秒检查：离线超过 120 秒、任务失败/结果未知、到期前 3 天、配额达到 80% / 100%；状态转换持久化去重，恢复时发一次通知。节点维护期间暂停检查。
- Telegram 和 HTTPS Webhook 可同时配置，Webhook JSON 为 `{"title":"通知内容","source":"Vaio Panel"}`。机器人令牌不回显。默认不启用外部通知，管理员保存配置后可发送测试。
- 通知记录保留 30 天。失败和发送中断的未知结果不会自动重发，避免重复通知；两个渠道的结果合并展示。通知队列每次最多发送 10 条。
- 每个数据库以文件锁选举一个后台线程，多 Gunicorn 工作进程不会重复扫描/发送。不要启用 Gunicorn `--preload`，不要将同一数据库部署在多个主机/NFS 上。测试可设置 `VAIO_MONITOR=0` 关闭后台线程。

## 备份与恢复

每日 UTC 日期变更后自动在线备份 SQLite，保留最近 7 份，目录默认为数据库同级 `backups/`，可用 `VAIO_BACKUP_DIR` 配置；目录 700、文件 600。恢复校验先复制到临时数据库，检查完整性、外键与版本，不替换在线数据库。备份包含节点身份摘要、登录配置及通知凭据，应由管理员妥善保管。此功能只备份面板数据库，环境配置由原有升级流程备份；代理配置仍在节点本地。

服务器管理命令：

```sh
vaio-panel backup
vaio-panel verify-backup --name panel-日期-标识.sqlite
systemctl stop vaio-panel
vaio-panel restore --name panel-日期-标识.sqlite
systemctl start vaio-panel
```

恢复前再次备份当前数据库；恢复后旧会话失效、安装凭据作废、排队任务取消、执行中任务转为结果未知，通知中的未完成投递转为未知。管理员需重新登录并核对节点状态，不自动重放任务。线上库使用向后兼容的新增表，程序升级失败可回到上一版本。

## 验证记录

本地覆盖计费周期、重复采样、计数器回零、手动停用、共享渲染器配额/到期执行、按实例写入及恢复、通知去重/恢复/维护、凭据脱敏、鉴权/CSRF、备份恢复及任务不重放。前端语法和既有安装表单回归通过；根脚本的计费、实时流量、Snell 用户、Sing-box 统计及 API 回归通过。浏览器检查新增页面与恢复校验。

本机旧版 OpenSSL 不支持 X25519 的原有测试跳过；Linux 部署环境会再次执行完整测试。真实 VPS 验证与本地模拟测试分开记录；尚未完成的节点链路验收不能据此宣称通过。
