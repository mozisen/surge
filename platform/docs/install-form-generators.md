# 安装实例表单自动填写

保留当前默认值及节点能力过滤，不额外开放未适配协议或参数。

- 自动生成端口：20000–65535，避开当前输入值和快照中已有的监听端口。仅提供建议，不声称检查过服务器所有进程；最终安装仍由 Agent 检查实际占用。

- SNI 恢复默认：恢复 www.cloudflare.com，不随机生成域名；Snell 禁用此项。
- 按协议说明 UUID/Reality 密钥/Short ID、PSK、密码/证书由服务端在安装时生成，不在浏览器生成或提前安装。
- 所有填写按钮使用 type=button；生成后支持手动修改并通过状态区域反馈。
