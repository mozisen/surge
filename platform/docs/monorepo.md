从仓库根目录运行 `cd platform` 后执行 Python 测试或 Docker Compose；根 CI 为 `.github/workflows/platform.yml`。
安装器与升级器从 surge 源码包提取 `platform/`，不再下载旧平台仓库。合并未进入正式分支前默认 ref 为 `codex/platform-api`，管理员可指定经审核提交。旧线上部署不会自动迁移或修改。

当前可写协议仍以能力表及适配器为准。全协议安装、修改、卸载、用户管理、跨资源事务仍需逐组实现并验证；未实现部分不得开放写入。

本次补强 Bridge 级事务日志（`transactions/`）：持久化执行意图与请求摘要；重复成功请求返回原结果；不同内容复用任务 ID 拒绝执行；中断/未知异常/恢复不完整均禁止自动重放并上报 unknown。配置写入同时同步文件及父目录；日志不保存请求凭据。既有五种可写组合复用此机制，原 Agent 外层任务日志继续保留。

本地验证：平台 52 项 Python 回归、根脚本十二套回归、前端 Node 语法、Shell 语法与 diff 检查；使用源项目既有 Python 3.9 虚拟环境运行测试，但没有复制该环境或更改其中依赖。Docker 镜像、Python 3.12 和真实 VPS/线上升级未在本地验证，需后续 CI/授权测试。当前不发布、不部署。
