# 协议配置详情

节点 Agent 0.3.0-preview.6 在实例用户列表的「配置信息」入口返回配置详情。输入实际使用的公网地址后，展示内核、端口、所选用户的 UUID/密码/PSK，以及脚本对应的客户端配置、连接文本和二维码。数据库已有的 IPv4/IPv6 会一并展示，不额外向外部服务查询地址或地区；客户端配置名称前缀使用「节点」。

客户端配置直接读取固定版本脚本 `show_single_protocol_info` 的显示模板，使用指定内核、协议、端口及用户数据；不调用交互菜单，不修改协议配置。支持当前受管的 VLESS、Hysteria2、Trojan、AnyTLS、SS、SS2022 与 Snell v4/v5/v6。Reality 私钥不返回。分享链接沿用现有生成逻辑，二维码编码的内容与连接文本一致。

结果仅管理员可读，10 分钟后不可读取，Agent 在结果确认后删除本地凭据结果；二维码在面板本地生成，无第三方二维码接口。旧 Agent 仍可导出原有连接，需升级后获得完整详情。本次无需修改 vless-server.sh。

验证覆盖各协议模板、指定用户凭据、私钥排除、二维码登录限制及过期访问。模拟验证不代表真实客户端连通测试。
