# v0.2.1 验证说明

## 2.1 验收记录（2026-09-21）

自动化：44 项测试通过，覆盖节点设置与回收站、旧数据库迁移、维护锁、版本诊断、未知任务人工核对、更新包路径校验，以及健康检查失败后的面板程序恢复。升级恢复测试使用隔离文件目录和模拟服务，不是故障注入真实 VPS 的结论。

真实环境：面板使用 Debian 12 amd64 / systemd，测试节点使用 Debian 13 amd64 / systemd。面板通过新升级器部署，节点从 0.1.0 保留身份升级至 0.2.1，重新上线并自动退出维护。节点名称/分组/备注接口修改后恢复原值。Snell v4/v6 独立测试实例安装、连接信息导出、客户端连接、重启、卸载成功。

VLESS Reality：独立端口安装、导出连接、新增用户、禁用后拒绝连接、重新启用后恢复连接、删除用户后旧凭据失效，以及修改端口后连接成功，均通过真实客户端验收。HTTPS 出口 IP 与测试节点一致。测试时 `www.microsoft.com` 在该节点的 Reality 握手失败，独立进程对照验证 `www.cloudflare.com` 可用；界面默认值和目标站说明已更新。目标可用性受节点网络影响，安装任务成功只代表配置与服务应用成功。

Hysteria2：真实安装、导出、重启、卸载，以及节点本机回环客户端访问 HTTPS 并核对出口 IP 均通过。主服务器到测试节点的公网连接未通过：客户端超时，节点定向抓包有请求进入与响应发出；主服务器复验记录发送 14 个测试 UDP 包、接收 0 个，两端主机过滤规则放行。证据指向这条公网链路的 UDP 回程问题，具体上游限制仍待排查，不能宣称公网 HY2 验收成功。未擅自更改云侧防火墙或用其他协议替代该验收。

GitHub Actions 已通过 Python 3.9/3.12 回归和容器构建：[检查记录](https://github.com/mozisen/vaio-panel/actions/runs/35563958154)。原有七个协议实例、原始运行配置中的 inbound 与 Agent 身份均与验收前备份核对一致。

浏览器：节点设置及备注保存通过；桌面与 375px 视口检查通过，无页面横向溢出。界面保持黑白中文风格。

待完成环境：干净 VPS 上完整的主面板首次安装与自动 HTTPS 签发、OpenRC、arm64、断电中断恢复，以及旧 Snell v5 迁移。当前没有用于首次安装验收的临时域名，未在现有面板上执行覆盖安装。

原有旧版 Snell v5 没有独立实例 ID，保持原状，未自动迁移；不能将 v4/v6 验收结论外推到该旧实例。

## 首版自动化覆盖与历史记录

- 登录、会话 Cookie、CSRF、登录限速、跨源登录拦截。
- 注册凭据单次消费、过期及并发消费。
- 节点接管、撤销、状态白名单、凭据不上报。
- 任务请求去重、单次领取、节点间结果隔离、结果重复提交、超时不重放。
- 配置版本冲突拒绝、单端口卸载保留其他实例、修改用户保留流量与 TG 信息。
- 配置失败后恢复原数据库与运行文件。
- 禁用全部用户不会恢复默认凭据。
- 保留相邻 inbound 与 routing，端口修改仅影响目标。
- Agent 重启标记不确定任务，结果回传失败后只回传结果。
- Agent 包确定性构建与 SHA-256 匹配。

系统服务、二进制下载及代理协议运行使用隔离模拟。测试不操作本机 `/etc`、不启动真实代理。

本地验收记录：29 项自动化测试通过；Python/JavaScript/Shell 语法检查通过。浏览器验证了登录、节点创建、安装脚本生成、模拟 Agent 经 HTTP 注册与心跳、接管、新增用户任务成功回传及用户数量更新。375px 宽度检查无页面横向溢出，浏览器未报告 JavaScript 错误。

开发主机未安装 Docker，因此容器构建交由仓库 CI 验证；本地未运行容器或真实 Linux 服务。

## 完整部署验收矩阵（未全部完成）

1. 主面板容器启动、证书签发、管理员登录。

6. 模拟配置校验失败与服务启动失败，验证自动恢复及备份。
7. 重启 Agent、重启节点、面板断网后恢复；确认任务没有被重复执行。
8. 检查端口冲突、旧版 Snell 多端口、HY2 端口跳跃等不支持场景被拒绝。
