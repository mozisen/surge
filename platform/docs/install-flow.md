# 协议安装流程优化

点击安装协议后，先选择节点支持的协议，再打开该协议的安装表单。同一协议的多个内核在表单内选择，不重复列入协议列表。

表单仅展示当前协议与节点版本支持的字段：VLESS 的 Reality 参数、TLS 协议的证书设置、SS 系列的加密方式、Snell v6 的连接设置。证书邮箱只在申请证书时展示。返回按钮可重新选择协议。切换协议重新建立表单，避免保留其他协议的参数。

本次只更新面板交互，无需额外升级 Agent；协议可用范围仍由节点能力决定。

验证：Python 回归测试、JavaScript 语法检查、安装表单行为测试，以及本地浏览器逐个检查 9 种协议表单。浏览器预览不提交真实安装任务。
