# Vaio Panel 协作规则

- 在 `codex/*` 分支开发。按明确功能拆分本地提交；不提交 `.env`、数据库、节点身份、安装脚本生成物或测试运行数据。
- 修改后运行 `python -m unittest discover -s tests -v`，涉及前端再运行 `node --check web/app.js`，涉及 Shell 运行语法检查。
- 节点写入必须按实例定位、检查配置版本、保存备份并处理失败恢复；不能用模拟菜单输入替代标准接口。
- 不自动重放结果未知的任务。不提供任意远程 Shell；扩展动作须同时更新面板和 Agent 校验及测试。
- `vendor/vless-server.sh` 保留来源与校验值；更新需同步来源文档并验证兼容性。
- 真实 VPS 与模拟测试的验证结论必须区分。没有用户明确授权，不操作生产节点或强制推送远程分支。

- 界面采用黑白简约风格，文案使用中文；不添加英文标语或装饰性英文。协议名、产品名和必要技术标识保留原名。
