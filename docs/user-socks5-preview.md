# v3.7.0-preview.2：用户 SOCKS5 路由

在「用户管理 → 修改用户路由 → 选择用户」中增加「SOCKS5 代理（选择/新增节点）」。支持选择已有 SOCKS 节点，或输入节点名称、IPv4/IPv6/域名、端口以及可选用户名和密码。密码输入不回显。

复用链式代理节点存储和核心出口生成逻辑，不改变全局规则；所选用户保存为 `chain:节点名`，界面中显示「链路→节点名」。可在链式代理节点管理中维护节点。新增用户时同样可选择此出口。

支持由 Xray / Sing-box 管理的用户（包括 AnyTLS）。官方 Snell 独立进程不支持此路由机制，继续显示原有说明。SOCKS5 的 UDP 能力取决于远端节点及核心实现。

测试：`bash tests/user-socks5-routing.sh`、`bash tests/snell-users.sh`、`bash -n vless-server.sh`。本地回归覆盖菜单、节点保存、认证/免认证核心出口、IPv6、非法输入及重载分派；未在真实服务器验证代理连通性。请在测试机验证单用户出口 IP 改变、其他用户仍走原路由，再用于生产。
