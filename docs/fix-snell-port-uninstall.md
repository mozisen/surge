# Snell 按端口卸载修复

原卸载菜单选择端口后进入 standalone 整组停止/删除分支，导致其他 Snell 用户实例同时被移除。

现在已管理的 Snell v4/v5/v6 在整组停止前分流，只调用所选端口用户的删除流程，清理对应服务、配置、规则和计数器。其余实例不停止、不重载、不改写。最后一个实例删除后清理协议数据库及管理标记；明确选择所有端口时才删除全部用户。

旧式未迁移多端口记录拒绝单端口卸载，避免误删。不存在的端口或异常记录拒绝删除。卸载成功显示剩余实例数量。

验证：Snell v4/v5/v6 双端口、保留用户流量及 TG 绑定、无效端口、最后端口/所有端口、菜单分流回归测试；原十套回归、语法及 diff 检查。服务和 nft 使用隔离模拟，未在真实 VPS 执行破坏性卸载测试。本次不发布版本。
