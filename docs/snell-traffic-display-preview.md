# v3.7.0-preview.8 本地预览记录

修复「同步流量数据 → 用户流量统计」将数据库分组展示绑定核心进程的问题。Snell 虽是独立进程，用户数据保存在 xray 分组；旧逻辑在 Xray 未运行时隐藏整个分组。

现在成功同步后按已保存协议数据展示累计用量，包含 Snell v4/v5/v6，不依赖 Xray 或 Sing-box 进程运行状态。此变更仅修正展示条件，不重置用量，不改变 Snell 防火墙计数、同步或服务配置。旧 Snell 未启用计数时仍需另行配置，显示条目不意味着已采集历史流量。

验证：Bash 语法、Git diff、七套离线回归测试；新增 Snell 三版本、混合协议、Xray 停止、仅 Snell 场景的展示测试。Linux 实际 Snell 计数采集不在本次本机验证范围内。

仅推送预览分支，不创建 GitHub Release。
