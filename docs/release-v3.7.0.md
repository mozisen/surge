# v3.7.0

## 新增与改进

- Snell v4/v5/v6 多用户实例：独立端口、密钥、DNS/模式设置，以及流量、配额和用户管理集成。
- 用户路由支持选择或新增 SOCKS5 出口节点。
- 完善 Sing-box 用户统计依赖、统计核心修复、实时查询及 VLESS/Trojan/HY2/TUIC/AnyTLS 流量入库。
- 支持 Sing-box 1.14.0 稳定版统计构建；后续稳定版按实际构建、配置和接口验证决定是否允许更新，不再按次版本号直接拦截。
- 已启用统计的核心升级保留统计能力，失败时恢复旧核心及配置。
- 修复零流量用户隐藏、Snell 在 Xray 未运行时累计用量不显示等问题。

## 菜单调整

- 「协议运行内核切换」移除“预览”字样。
- 删除用户管理 f 诊断菜单及相关过期提示；统计修复仍可在实时统计/同步页面确认重试，失败日志保留。
- 「p：Snell 用户实例设置」只列出已安装的 Snell v4/v5/v6，不再出现 VLESS 等其他协议。

## 升级注意

Snell 多用户采用独立进程及防火墙计数，不是共享端口多密钥。迁移后不要直接回退到不支持这些实例的旧脚本。已有凭据和累计用量不会因本次菜单调整被重置。

统计核心源码构建需要网络、内存和磁盘资源，重启会中断现有连接。此前未采集的历史流量无法追回。未来核心版本只有验证通过才能升级，不能预先保证兼容。

## 验证

Bash 语法、Git diff 与八套离线回归测试通过；使用 Sing-box 1.14.0 在本机完成 VLESS/AnyTLS/Trojan 实际回环计数及 reset 测试。Linux systemd/OpenRC 核心替换和回滚、Snell 防火墙现场行为未在本机集成验证，建议保留备份。
