# v3.7.1

## 流量统计改进

- Sing-box 统计核心改为下载预编译包，服务器无需安装 Go 或现场编译。
- 开启/修复统计时检查官方最新 1.14.x 稳定版本，不一致时提示先更新核心；不会自动升级或降级。已健康运行的统计接口不强制升级。
- 自动识别 amd64/arm64 与 glibc/musl，校验平台清单、归档和二进制 SHA-256。
- 提供 1.14.0 的四类预编译包，全部通过各自平台的 VLESS、AnyTLS、Trojan 实际流量及重置测试。
- 没有对应包时提示手动本地编译，下载失败不会自动编译或更换原核心。
- 保留核心及配置备份、服务重启、接口验证和失败恢复流程。

## 注意事项

核心替换会短暂中断连接，仍需解压及备份空间。未来版本需先构建并验证对应包，不保证自动兼容。流量统计口径及历史累计数据不作变更。
