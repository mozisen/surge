# v3.7.0-preview.7 本地预览记录

## 变更

- 已有失败记录时，进入实时统计或同步页面会提供「是否现在重试修复」，选择 y 后进入修复确认流程；回车跳过，不会未经确认自动编译。用户管理 f 仍可直接诊断/重试。
- 取消 1.10–1.14 次版本白名单，接受完整稳定语义版本（含可选 v 前缀），不接受预发布和异常输入。未来版本只获得尝试构建的资格，不代表已经验证兼容。
- 检测当前核心带统计能力或当前配置启用统计时，指定版本更新、常规核心更新和强制安装入口统一保留统计构建，不直接覆盖为无统计的官方发布包。
- 构建目标版本时不先停旧服务；目标二进制须通过统计标签、版本号和现有配置检查，才备份并替换。更新保留已验证的现有配置，避免自动重写设置。
- 替换后重启并检查 gRPC API；失败恢复旧核心、配置并重启，恢复失败给出备份路径。更新前停止的服务在临时验证后恢复停止状态。版本兼容性或构建失败时拒绝升级，不降级、不禁用统计来绕过检查。
- 统计保留更新目前仅支持稳定版；预发布通道明确拒绝。

## 验证范围

六套离线测试覆盖版本解析、菜单重试、三个更新入口、构建前不停止服务、失败传递、停止状态恢复，以及原有统计入库/Snell/SOCKS5 功能。Bash 语法与 diff 检查通过。

实际回环流量测试使用已构建的 Sing-box 1.14.0，验证 VLESS、AnyTLS、Trojan 命名用户计数和 gRPC reset。未来 1.15+ 不作已经实测的承诺。Linux 上核心替换/恢复及 systemd/OpenRC 生命周期未在本机验证；请在测试服务器确认后再用于生产升级。

仅本地记录并推送预览分支，不创建 GitHub Release。
