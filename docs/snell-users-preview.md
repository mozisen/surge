# v3.7.0-preview.1 — Snell 多用户

官方 Snell v4/v5/v6：一个用户对应一个端口、PSK、配置文件和服务进程；同版本共用核心二进制。现有 Xray/Sing-box 协议保持原有管理方式。

## 使用

1. 使用预览脚本进入「用户管理 → 添加用户」，选择已安装的 Snell 协议。
2. 首次添加会安装 nftables 依赖，并将原始配置迁移为 default 用户。保留端口、PSK、DNS、混淆配置、累计用量与 TG 绑定；迁移会短暂重启该版本的原服务。
3. 输入新用户名、独立端口、配额和有效天数。新用户继承默认实例的 DNS/模式，获得随机 PSK。
4. 在用户管理中设置配额、到期、启用/禁用、TG 绑定；通过 s 查看可复制的 Surge 配置。
5. 通过 p 修改单个用户端口、重新生成 PSK、设置 DNS，以及 v6 default/unshaped 模式。
6. 云安全组与外部防火墙需允许用户端口。v5 QUIC Proxy Mode 需要 UDP。

## 统计口径

使用独立 inet vless_snell_users 表，按客户端端口累计 TCP/UDP、IPv4/IPv6 上下行网络字节。含协议开销、重传和未认证连接流量，不是应用净流量，也不统计 Snell 出口侧以免重复计费。不会清空 nftables 转发表。

计数器不 reset；累计用量与计数基线在同一数据库事务中写入。计数器重建使用新 generation，避免重启后负增量。规则被外部清空或主机断电时，最后一次同步之后的尚未落盘数据可能丢失。

添加用户会设置每分钟同步，超额或到期停止对应服务，TG /traffic 复用同一同步锁。配额可能超出一个检查间隔的流量。月重置复用现有设置；已禁用用户需要在额度/日期恢复后手动启用。

## 迁移和运行

配置与迁移备份位于 /etc/vless-reality/snell-users，用户服务名为 vless-snellu-固定ID。systemd/OpenRC 服务启动前检查账号权限并恢复计数规则。

首次自动迁移只接受旧版单端口、至多一个用户记录的原生 Snell 配置。历史多端口配置缺少可靠的逐端口原始文件映射时会拒绝迁移，以免丢失自定义配置。ShadowTLS 组合协议不在本次多用户范围。

官方 Snell 实例不使用 Xray/Sing-box 用户路由。启用多用户后，不能直接回退到不认识 --snell-prepare 的旧脚本；应先迁移或卸载实例。主机重启及升级核心都应在实机测试中验证。

## 验证

运行 bash tests/snell-users.sh。覆盖旧凭证与 TG 绑定保留、迁移幂等、重复同步、新计数器代次、配额与到期禁用、禁用用户不随组启动、v4/v5/v6 Surge 输出。

本地测试不启动 Linux 服务、不加载防火墙，也不发 TG 消息。预览版仍需在 Debian/systemd 与 Alpine/OpenRC 实机验证进程启动、重启恢复、TCP/UDP 连接、TG 查询及 nftables 共存。
